Новые каталоги `/cars/` и `/equipment/` используют `assets/catalog-offers.json`: 26 актуальных автомобилей из 32 сохранённых, 31 позиция техники, включая 10 новых. Курсы: `scripts/update-currency-rates.py` читает официальный ежедневный XML ЦБ РФ с учётом номинала. `assets/live-pricing.js` проверяет опубликованный снимок каждые 5 минут; это ежедневный справочный курс, не биржевые тики. GitHub Actions получает курсы каждый час и при публикации. При ошибке сохраняется последняя версия с видимой датой; workflow сообщает ошибку.

Подтверждённая валютная часть: США — USD, Китай — CNY, Корея — KRW, Япония — JPY. Для Кореи/Китая индексируется валютная цена покупки внутри прежней общей оценки; фиксированные рублёвые платежи не умножаются целиком на курс. Подтверждённые EUR/см³ меняются с EUR. Остальные импортные компоненты предварительные, их проверяют до согласования. Для США сохраняется прежняя цена покупки, импорт отдельно. Рублёвые предложения без подтверждённой валютной базы остаются фиксированными. Для оборудования есть отдельные предварительные расчёты РФ/КР, доставка отдельно; расчёт не открывает недоступное направление.

Оформление: единая закреплённая шапка, компактная сводка заказа, суммы в вариантах оплаты, общий PDF как главное действие и отдельные компактные счета. На мобильных ввод использует шрифт 16px, кнопки — не менее 44px. Повторное независимое UX-ревью: дизайн 9,0/10, удобство 9,2/10 (Chromium 320/390/1440; не аудит физических устройств или банковских платежей).

Общий заказ: один договор и спецификация, цена каждой строки фиксируется при формировании. Покупатель выбирает полную предоплату либо 50/50 при любой стоимости. При выборе 50/50 сразу выдаются два счёта с разными номерами и одной фактической датой составления, каждый с QR на свою сумму. Второй счёт не подтверждает оплату аванса или готовность товара; срок доплаты — 10 календарных дней со дня, следующего за получением уведомления TE GROUP. Оба счёта входят в общий PDF и доступны отдельно. Сохранённый исходный комплект используется для повторного формирования; номер и дата второго счёта сохраняются. Для старых документов без явного выбора поддерживается прежний график по порогу 3 млн ₽. Повторный счёт импортирует исходный PDF с проверкой видимого состава, сумм, условий и реквизитов; отсутствующий VIN/SN требует подписанной согласованной спецификации. Проверяется остаток каждой строки, уже оплаченные позиции повторно не оплачиваются.

Обновления компонентов: сборка формирует адреса JavaScript/CSS с хешем содержимого; PDF-компоненты загружаются с версией из SRI-манифеста. Это предотвращает смешивание новой страницы со старым CDN-кэшем.

Конфиденциальность: поля не отправляются и не сохраняются. SessionStorage содержит только публичные ID товаров и страну назначения. PDF/QR формируются локально; цена фиксируется в PDF. Документ не подтверждает оплату, бронь или подписание.

Публикация: GitHub Pages настроен на GitHub Actions. Workflow `currency-rates.yml` обновляет официальный снимок курсов, сохраняет его и непосредственно публикует Pages. При недоступности источника сохраняется предыдущий снимок, ошибка отражается в workflow. Первичная публикация и получение курсов проверены 23.10.2026.

Сборка: `TE_SOURCE_DIR=/absolute/non-public/source npm run build`; исходники документов находятся вне публичного репозитория. Проверки: `npm test`. Локальный просмотр: `python3 -m http.server 8000 --bind 127.0.0.1`.

## Документы и конфиденциальность

Главная — отдельный HTML без каталога и скриптов формы, поэтому каталог не появляется при её загрузке. `/cars/` генерирует и показывает PDF локально; кнопки «Скачать» и «Открыть» используют один временный Blob. PDF.js загружается с этого же сайта только при открытии просмотра. Исходные PNG водяных знаков сохранены; для PDF используются иллюстрации в исходном разрешении с подготовленной прозрачностью и JPEG-сжатием высокого качества. Текст и QR векторные, факсимиле сохранено без изменения пикселей. Проверенный пакет — около 1,9 МБ.

Поля анкеты не передаются по сети, не помещаются в URL, localStorage, sessionStorage или IndexedDB. Закрытие оформления и `pagehide` очищают поля и отзывают Blob URL. CSP автомобильной страницы запрещает отправку форм, сторонние скрипты, встраиваемые объекты и сторонние сетевые соединения. Не подключайте аналитику, запись сессий или сторонние виджеты к `/cars/`. Скачанные файлы остаются под контролем покупателя. Пользователь с доступом к браузеру может исследовать собственные введённые данные в DevTools — клиентский код не может скрыть их от владельца устройства.

## Производственная сборка и границы защиты

Собственные скрипты минифицированы и обфусцированы локально; source maps не создаются. `cars/index.html` проверяет целостность загружаемых скриптов через SRI и сохраняет CSP без `unsafe-eval`. Устаревший HTML предпросмотра снят с публикации. Аналитика и запись сессий Яндекс.Метрики отключены на товарных страницах.

Редактируемые исходники хранятся отдельно от публикуемой сборки. Для пересборки: `npm ci --ignore-scripts`, затем `TE_SOURCE_DIR=/путь/к/редактируемым/исходникам npm run build`. Не редактируйте обфусцированные файлы вручную. После изменения любого JS обновите его SRI в `cars/index.html` и версии ресурсов. Зависимости инструментов зафиксированы в lock-файле. Сохранённый исходный снимок сборки указан в `production-build.json`.

Обфускация затрудняет поверхностное чтение кода, но не обеспечивает секретность: браузер получает публичные ресурсы, в том числе реквизиты и факсимиле, необходимые текущему локальному генератору. Предыдущие читаемые версии уже доступны в истории открытого репозитория. Новый коммит не отменяет их прежнюю публикацию.

Серверный перенос факсимиле и внутренних алгоритмов **не развёрнут**: требуется отдельный хостинг и контроль доступа. GitHub Pages выполняет только статическую часть. Не добавляйте серверные ключи, токены, анкеты или заполненные PDF в этот репозиторий. До серверного перехода сохраняется проверенная локальная обработка анкет без передачи данных; нельзя представлять обфускацию как выполненный серверный контроль доступа.

Проверка PDF: `node tests/documents.cjs` (цены 32 предложений, фиксация суммы, QR payload, семь страниц и размер менее 2 МБ). Для сохранения тестового PDF задайте `PDF_OUTPUT` с локальным путём; тестовые данные вымышленные.

Для tegroup.cc и www.tegroup.cc добавлен ранний переход на HTTPS; обработчик анкеты не запускается на HTTP. Это запасная мера в коде страницы. 12.10.2026 в Cloudflare включены Always Use HTTPS, минимальный TLS 1.2, HSTS на 30 дней (`max-age=2592000`, без includeSubDomains и preload), `X-Content-Type-Options: nosniff`. Проверены HTTP → HTTPS (301), ответ HTTPS (200) и заголовки на `/cars/`. Проверка публичного сайта после изменения заголовков прошла: каталог, генерация семистраничного PDF менее 2 МБ, просмотр PDF, отсутствие передачи данных анкеты и ошибок ресурсов.

Режим Cloudflare → origin остаётся Full: он шифрует соединение, но не проверяет подлинность сертификата origin. Full (strict) ещё не включён: API GitHub Pages ранее сообщил об отсутствии сертификата Pages. Перед переключением необходимо выпустить и проверить сертификат origin для домена. При переносе DNS или отключении Cloudflare сохраняйте рабочий HTTPS: браузеры запоминают HSTS на указанный срок. Настройки Cloudflare действуют независимо от публикации GitHub Pages.

В карточках также опубликован предварительный бюджет «техника + таможня и утильсбор» для коммерческого ввоза в РФ на 19.10.2026. Доставка, страхование, услуги, СВХ и разрешительные документы отдельно; город назначения не является условием просмотра ассортимента. Автомобильный договор и инвойс к спецтехнике не применяются автоматически. Публичный номер позволяет искать упоминания и запросить сервисные записи, но не подтверждает чистую историю.

Расчёты воспроизводятся командой `python3 scripts/equipment-customs.py`, проверяются `python3 tests/equipment-customs.py`. Используются Decimal и округление каждого платежа до копеек. Таможенный сбор рассчитан на одну машину в отдельной декларации. НДС 22% включён полностью, без вычета.

Для Caterpillar применён сценарий американского происхождения с пошлиной 30% (ПП РФ № 2240). Диапазон утильсбора F04–F05 сохраняется до проверки номинальной мощности конкретного двигателя; значения net и ISO 14396 у модели различаются. Для Hyundai — сценарий корейского происхождения, пошлина 5%, категория C03. Для дорожных самосвалов старше 7 лет — 1 EUR/см³ по предварительному коду 8704239801 и утильсбор 150000 × 66,44 (строка 18¹ на 2026 год); объёмы двигателей приняты номинальными по модели и требуют проверки по документам. Наличие объявления и страна размещения не подтверждают страну происхождения, возможность экспорта или классификацию.

Это не фиксированная цена ввоза: в исходном сценарии транспортные расходы до места прибытия в ЕАЭС равны нулю, поскольку тариф ещё не определён. При появлении тарифа их нужно включить в таможенную стоимость и пересчитать пошлину, НДС и при необходимости таможенный сбор; реальные расходы на логистику добавляются отдельно. Не публиковать эти суммы как готовое коммерческое предложение без проверки документов, происхождения, маршрута и курса на дату декларации.
