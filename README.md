# TE GROUP — товары и автомобили

Статический сайт для GitHub Pages: `/` — два направления, `/goods/` — сохранённый прежний товарный сайт, `/cars/` — автомобильный каталог. Прямая ссылка `/cars/?car=ID` открывает выбранную машину. `auto-src/` содержит редактируемые исходники и датированный снимок каталога.

Для локального просмотра: `python3 -m http.server 8000 --bind 127.0.0.1`, затем http://127.0.0.1:8000/ . В каталоге 25 сохранённых объявлений; автоматическое обновление не подключено. Анкета покупателя обрабатывается локально и очищается при закрытии. PDF содержит договор, спецификацию, счёт с суммой и QR, отдельное согласие. Сумма фиксируется в момент создания документов. Генерация PDF не подтверждает подписание договора, бронь или оплату.

Публикация версии от 12.10.2026 одобрена владельцем. GitHub Pages публикует корень ветки `main` на https://tegroup.cc/. Банковские реквизиты и исходные факсимиле компании находятся в клиентских ресурсах. Данные покупателей и заполненные документы в репозиторий не включаются.


## Документы и конфиденциальность

Главная — отдельный HTML без каталога и скриптов формы, поэтому каталог не появляется при её загрузке. `/cars/` генерирует и показывает PDF локально; кнопки «Скачать» и «Открыть» используют один временный Blob. PDF.js загружается с этого же сайта только при открытии просмотра. Исходные PNG водяных знаков сохранены; для PDF используются иллюстрации в исходном разрешении с подготовленной прозрачностью и JPEG-сжатием высокого качества. Текст и QR векторные, факсимиле сохранено без изменения пикселей. Проверенный пакет — около 1,9 МБ.

Поля анкеты не передаются по сети, не помещаются в URL, localStorage, sessionStorage или IndexedDB. Закрытие оформления и `pagehide` очищают поля и отзывают Blob URL. CSP автомобильной страницы запрещает отправку форм, сторонние скрипты, встраиваемые объекты и сторонние сетевые соединения. Не подключайте аналитику, запись сессий или сторонние виджеты к `/cars/`. Скачанные файлы остаются под контролем покупателя. Пользователь с доступом к браузеру может исследовать собственные введённые данные в DevTools — клиентский код не может скрыть их от владельца устройства.

Для изменения опубликованных документов редактируйте `auto-src/premium-pdf.js`, интерфейс — `auto-src/app.js`, `auto-src/pdf-preview.js` и `auto-src/document-ui.css`. Основная страница — `index.html` и `assets/home.css`, автомобильная — `cars/index.html`. При публикации изменяйте версии ресурсов в ссылках. `auto-src/index.html` — архивный шаблон предыдущего предпросмотра, не точка сборки опубликованного сайта.

Проверка PDF: `node tests/documents.cjs` (цены 25 предложений, фиксация суммы, QR payload, семь страниц и размер менее 2 МБ). Для сохранения тестового PDF задайте `PDF_OUTPUT` с локальным путём; тестовые данные вымышленные.
