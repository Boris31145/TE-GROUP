# TE GROUP — товары и автомобили

Статический сайт для GitHub Pages: `/` — два направления, `/goods/` — сохранённый прежний товарный сайт, `/cars/` — автомобильный каталог. Прямая ссылка `/cars/?car=ID` открывает выбранную машину. `auto-src/` содержит редактируемые исходники и датированный снимок каталога.

Для локального просмотра: `python3 -m http.server 8000 --bind 127.0.0.1`, затем http://127.0.0.1:8000/ . В каталоге 25 сохранённых объявлений; автоматическое обновление не подключено. Анкета покупателя обрабатывается локально и очищается при закрытии. PDF содержит договор, спецификацию, счёт с суммой и QR, отдельное согласие. Сумма фиксируется в момент создания документов. Генерация PDF не подтверждает подписание договора, бронь или оплату.

Публикация версии от 12.10.2026 одобрена владельцем. GitHub Pages публикует корень ветки `main` на https://tegroup.cc/. Банковские реквизиты и исходные факсимиле компании находятся в клиентских ресурсах. Данные покупателей и заполненные документы в репозиторий не включаются.
