# Контракт нормализованной выгрузки

JSON-массив предложений или объект `{"offers": [...]}`. Обязательные поля одного предложения:

```json
{
  "source": "westmotors",
  "source_id": "unique-seller-lot-id",
  "country": "US",
  "title": "Название конкретного автомобиля",
  "year": 2023,
  "mileage_km": 45000,
  "fuel": "Бензин",
  "source_url": "https://westmotors.ru/path-to-actual-lot",
  "image_url": null,
  "source_price_rub": 2500000,
  "source_currency": "USD",
  "source_price": 25000,
  "price_kind": "fixed_purchase",
  "price_basis": "Точный состав цены источника, пункт доставки, включенные и исключенные расходы",
  "description": "Факты о конкретном автомобиле"
}
```

Все значения выше — пример формата, а не реальное предложение или известный курс валют. Цены должны поступать из актуальной выгрузки или проверенного расчета с записанными исходными данными.

- `country`: только `US`, `KR`, `CN`. Это рынок/страна отправления конкретной машины, а не страна бренда.
- `source_id`: стабильный уникальный идентификатор конкретного объявления, не наименование модели.
- `source`: соответствует настроенному адаптеру/параметру команды import.
- `price_kind`: `fixed_purchase` — фиксированная покупная цена; `source_estimate` — оценка источника; `auction_bid` — ставка торгов. Ставки не выводятся как доступные покупки.
- `source_price_rub`: положительное целое число либо `null`, если рублевого расчета нет. Отсутствующая цена не заменяется случайным курсом или числом.
- `price_basis`: состав и границы оценки обязательно раскрываются клиенту. Рублевый эквивалент покупки за рубежом сам по себе не является бюджетом доставки в РФ.
- `mileage_km`: число либо `null`; для округленной оценки добавить `mileage_approx: true`.
- `image_url`: только разрешенная к использованию фотография источника; для нового источника требуется явное разрешение хоста в медиапрокси. Произвольный URL клиента не принимается.

При импорте смета TE GROUP не создается автоматически. Сотрудник подтверждает VIN, доступность продавцом, автомобиль/доставку/комиссию/расходы покупателя, пункт передачи и условия. Эта смета задает сумму компании и полный бюджет. Условие бронирования — не более 6 млн ₽ по полному бюджету. Номер подтверждения продавца хранится в журнале.

В полную выгрузку входят все актуальные предложения этого источника. Удаленные из полной выгрузки снимаются с публикации, но снимки уже созданных сделок сохраняются. Для частичного каталога `authoritative: false`: отсутствие в подборке не означает продажу.
# Сведения по автомобилям США

Для карточки состояния доступны дополнительные поля `damage` (повреждения),
`title_status` (документы автомобиля), `inspection_note` (история и осмотр),
`repair_note` (условия включения ремонта). Передавайте только подтвержденные
сведения конкретного лота. Пропуски отображаются как «Данные не предоставлены».
Изменение любого из этих полей требует новой сметы и подтверждения продавца.
Поле `vin` и VIN утвержденной сметы относятся к конкретному автомобилю.

Адаптер CarsFromUSA сохраняет цену Buy Now как `source_price` в USD с
`source_price_rub: null` и `intake_only: true`. Текущая ставка не используется
как цена выкупа. `source_expires_at` содержит время торгов; истечение
консервативно блокирует смету и бронь до обновления записи источника.
Менеджер подтверждает `inspection_reference`, `export_document_reference`
и явно задает `repair_rub`. Полный бюджет равен сумме компании плюс
`buyer_costs_rub` и `repair_rub`; ремонт не прибавляется повторно внутри
расходов покупателя. Сведения источника не являются подтверждением
экспортной пригодности или самостоятельным таможенным расчетом.
